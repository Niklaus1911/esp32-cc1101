## Firmware downloads

Each board has its own image. Never install one profile's image on another board, and never use OTA to change profiles.

| Board profile | Chip | Flash / PSRAM | Download |
|---|---|---|---|
| `esp32-devkit` | ESP32 | 4 MB / none | `rfbridge-v1.1.0-esp32-devkit.zip` |
| `esp32s3-devkitc-n16r8` | ESP32-S3 | 16 MB / 8 MB Octal | `rfbridge-v1.1.0-esp32s3-devkitc-n16r8.zip` |
| `xiao-esp32s3` | ESP32-S3 | 8 MB / 8 MB Octal | `rfbridge-v1.1.0-xiao-esp32s3.zip` |
| `esp32s3-supermini-fh4r2` | ESP32-S3 | 4 MB / 2 MB Quad | `rfbridge-v1.1.0-esp32s3-supermini-fh4r2.zip` |

Each zip contains the application image, bootloader, partition table, initial OTA data, a `flash_args` file with offsets, checksums, and license notices. The standalone `rfbridge-v1.1.0-<profile>.bin` assets are the same application images, provided for OTA. `SHA256SUMS` covers every asset.

### Update from v1.0.x (OTA)

Use **Web UI > System > Firmware update** with `rfbridge-v1.1.0-<profile>.bin`, or from a source checkout:

```bash
tools/push-ota.sh <hostname>.local rfbridge-v1.1.0-<profile>.bin
```

The device must be on Wi-Fi in service mode `web` or `both`, and the image's profile must match the running board.

### First install, or a board running other firmware (wired)

Extract the zip for your board, then from inside that folder:

```bash
# Optional but recommended if the board already holds learned signals or network settings:
esptool --chip <esp32|esp32s3> --port <serial-port> read-flash 0x9000 0x6000 nvs-backup.bin

esptool --chip <esp32|esp32s3> --port <serial-port> write-flash @flash_args
```

`flash_args` preserves NVS at `0x9000` (size `0x6000`). **Do not run `erase-flash`**, and do not merge these files into one image: padding the gap between the partition table and OTA data would wipe NVS.

## Safety

The Web UI and OTA endpoint are intentionally unauthenticated: anyone on the LAN can control the radio and install firmware. Only run it on a trusted network and never expose port 80 to the Internet. Use the CC1101 at 3.3 V only, always with an antenna, and follow your local RF regulations.
